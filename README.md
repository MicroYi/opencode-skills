# OpenCode Skills

可复用的 OpenCode / Claude agent skills 集合。

## 使用方式

```bash
# 全局安装（所有项目可用）
git clone https://github.com/MicroYi/opencode-skills.git ~/.config/opencode/skills

# 或单个项目使用
cp -r maintain-agents/ your-project/.opencode/skills/maintain-agents/
```

## Skills 列表

| Skill | 描述 |
|-------|------|
| [maintain-agents](./maintain-agents/) | Session 结束时自动审查并更新 AGENTS.md，归档旧日志 |
